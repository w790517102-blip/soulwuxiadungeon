## 提示規格摘要
劍：連鞘平放，低矮橫向，左握柄右鞘尖，向中央略斜，舊銅與深皮革。
書：線裝軟封，半開微卷紙葉，褪色深封與舊米紙，低視角。
茶具：低矮深色壺＋一淺杯，左壺嘴朝畫面中央，右杯，沉色銅／陶質感。
燈飾：大部分在畫面外，只露極窄舊銅框與微暖燭光，竹紋紙面。
共同：右上暖光、左側暗面、乾筆與細墨輪廓、柔和接地影、真透明背景、無UI或文字。
