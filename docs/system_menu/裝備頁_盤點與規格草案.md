# 裝備頁改版｜現況盤點與規格草案

> 依據：共邊國交接信（三區配置、飾品二→機關、小規模紙娃娃）、概念圖《水墨江湖裝備界面》、現有程式（2026-10-19 盤點）。
> 概念圖只當美術與版面參考；圖上的角色名、職業、等級、數值、裝備名稱都**不是**遊戲設定，一律接專案現有資料。

## 一、現況（程式裡已經有什麼）

| 項目 | 現況 | 位置 |

| 裝備欄 | 8 欄：`weapon_1`、`weapon_2`、`armor_head`、`armor_body`、`armor_hands`、`armor_feet`、`accessory_1`、`accessory_2` | `InventorySync.EQUIP_SLOTS` |

可以直接沿用：裝卸流程、數值加總、武器限制、存檔結構、道具頁的選隊友與確認視窗、已驗收的背景／導航／按鈕／稀有度章／前景（隨機兩方案）、盤纏框。

## 二、飾品二 → 機關：要動到的地方

欄位改名不改 id 的話最省事：`accessory_2` 仍是存檔欄位，**顯示名**與**判定**改成機關。建議改成新 id `mechanism`，並做相容轉換。

| 位置 | 要做的事 |
|---|---|
| `InventorySync.EQUIP_SLOTS`、`_migrate_equipped_entry` | 新增 `mechanism`；舊存檔的 `accessory_2` 有裝東西時，搬到空的 `accessory_1`，兩格都滿就留在背包（卸下），不丟物品 |
| `ItemDB._normalize_equip_slot` | `mechanism` 為合法欄位；舊的 `accessory_2` 道具資料（目前資料庫裡沒有）也轉成 `accessory_1` |
| `CharacterSkill.gd:317`、`SkillExecutor.gd:418`、`SkillDB.gd:1794`、`old_man_a.gd:293` | 這四處各自寫死 8 欄清單，要一併換成 `mechanism`（建議改成引用 `InventorySync.EQUIP_SLOTS`，避免再漏） |
| `ItemIconMap.gd:58` | 機關欄的預設圖示組（目前 `accessory_1/2` 都用第 11 組飾品） |
| 道具分類 | 機關道具 `type` 仍是 `equipment`，分類頁屬「裝備」；詳情的「品類」要能顯示「機關」 |
| 舊頁 `system_menu.gd` | 新頁上線後舊頁保留（旗標關閉時），按鈕文字「飾品二」改「機關」 |
| 測試 | 補：舊存檔 `accessory_2` 相容轉換、機關欄只接受機關道具、存讀檔後保持 |

## 三、諸葛連弩現況與待老闆決定的玩法問題

現況：`tool_zhuge_crossbow` 是**戰鬥中使用的消耗品**（`use_action: consume`、`no_consume: true`），每次耗箭矢 `ammo_arrow`，連發數 = 敏捷 ÷ 10 ＋ 1（上限 5），威力 18。商店 120 文。**目前不能裝備。**

要變成「可裝備機關」，下面幾點需要老闆決定（程式先不動）：

1. **彈藥**：沿用箭矢消耗？每發 1 支？箭矢用完怎麼辦？
2. **使用次數／冷卻**：每場戰鬥幾次？有沒有冷卻回合？
3. **行動消耗**：發射佔用一次行動，還是不佔？
4. **發動方式**：戰鬥選單的「道具」裡出現「發射」，還是裝備後自動觸發（例如每回合開始）？
5. **誰能裝**：每位角色都能裝，還是限定職業？
6. **既有的諸葛連弩**：玩家背包裡已有的，改成可裝備的機關即可（同一個 id），消耗品用法是否保留？
7. **裝備數值**：機關是否也有 `stats`（影響詳情的「裝備效果」比較表）？

資料對應：
- 「品質」→ 道具稀有度（凡品／良品／稀有／傳說，沿用道具頁章）。
- 「重量」：**專案沒有重量欄位**，先不顯示（或老闆決定是否新增）。
- 「整備」：**專案沒有對應功能**，待老闆決定（例如一鍵換成最佳裝備，或先拿掉）。
- 數值比較：只列專案有的 `STAT_KEYS`（atk、def、max_hp、max_mp、speed、accuracy、evasion、crit_rate_bonus）。
- 左側隊友卡：只列已解鎖的隊友；目前只有劉語塵，其餘兩位的卡片要能容納空位。
- 鎖定欄（書生副武器）要有停用樣式。

## 五、紙娃娃（小規模）——需要美術補的素材

這一階段只做**中央立繪**，單一角色（劉語塵）、一件諸葛連弩的裝備／卸下。

1. **人物底圖**：劉語塵全身立繪，透明背景，**不含**弩與背帶；3/4 側身，面向畫面右前方（概念圖的姿勢）。尺寸 2× 像素，約 900×1360（邏輯約 450×680），可超出中央區上下 20 邏輯像素。
2. **圖層拆分**（由後到前）：後髮／披風後片 → 身體 → 披風前片 → 機關掛載層 → 背帶／扣具 → 頭髮前片／肩膀遮擋層。至少要能讓機關夾在「披風」與「肩膀」之間。
3. **機關掛載**：諸葛連弩掛在角色自己的**左肩**（畫面位置隨朝向變）。請在規格圖標出：掛點座標（以底圖左上角為原點的像素）、旋轉角度、縮放。弩單獨一張透明 PNG（約 360×220 像素，2×）。
4. **背帶／扣具**：獨立透明 PNG，讓弩看起來固定在身上；跟弩分開，卸下時整組消失。
5. **示範**：一張「裝備前／裝備後」並排預覽，以及圖層順序圖。
6. 其他部位（頭、身體、手、足、武器）這一階段不做紙娃娃，只放槽內圖示；是否擴充，看示範通過後決定。
