# 《語破江湖》概念圖原像素摳圖版

本包從老闆提供的三張局部截圖製作透明遮罩，保留截圖原本的像素、筆觸、光線與柔焦。沒有用圖像生成重畫物件，也沒有補畫原本被畫面邊緣裁掉的部分。前一包重繪素材繼續保留，可作另一套選擇。

## 原尺寸版本：original_pixels/
五張獨立透明 PNG：
- sword_cloth_corner_original.png：劍、深色布料與後方露出的捲物，整組左下角構圖。
- teapot_corner_original.png：原畫右下角茶壺，保留柔焦、右側及底部貼邊裁切。
- scroll_roller_right_original.png：卷軸右側紙軸及軸頭，不是完整空白卷軸底板。
- scroll_tassel_right_original.png：右側掛繩、金屬垂飾與紅褐流蘇。
- candle_corner_original.png：原畫右上燭台與火焰，右側原本即被畫面邊界裁切。

原尺寸五圖逐像素比對 RGB，與來源截圖對應區域一致；只更動 Alpha 並裁透明邊。擷取畫面的檢視器底條已移除。
這些是畫面邊緣素材，應貼對應螢幕邊角使用；不要置於畫面中央，否則會露出原始構圖的裁切邊。

## 現有前景檔名套用版：assets/UI/inventory/
- fg_sword.png：514×142，左下角貼2×畫面(0,1296)。本圖已包含布料與後方捲物，採用時停用前一包的 fg_book，避免兩套前景重疊。
- fg_teapot.png：106×116，右下角貼(2304,1296)。依原規格最高116實體像素等比縮小；原尺寸版本另保留。
- fg_candle.png：37×74，右上角貼(2304,140)。保留原畫的局部燭台。
這三張在2304×1296畫面疊圖後，已檢查 Alpha 沒有碰到規格中的卷軸、分類欄、底部按鈕。卷軸右軸與流蘇另由工程端作裝飾替換及對位，未強行疊在既有卷軸上，以免出現雙軸。

套用版可能經等比縮小，會產生取樣差異；「原像素不變」的逐像素驗證指 original_pixels 五圖。
原圖接地影保留在可辨識的物件輪廓內，沒有額外套新亮光或調色；目前桌面本身的光影可用於接合。
