## 四、文字與顏色規則（程式輸出）
- 左頁（裝備格、人物區）：沿用道具頁的字色（深墨字／奶油字）。
- **右頁所有文字：白字加黑色外框**（避免被紙面山水吃掉）。素材請讓右頁偏淡、少大面積深色，我們疊字時才不會混。
- 數值增減顏色：增加＝綠、減少＝紅、不變＝灰。

### 圖層（由後到前，皆為透明 PNG，**同一張畫布 508 × 972 像素（2×）**，左上角對齊）
| 序 | 圖層 | 說明 |

| 1 | `doll_back` | 後髮、披風後片 |
| 2 | **`doll_mech_back`（機關後層）** | 機關被身體／披風擋住的部分（預留） |
| 3 | `doll_body` | 身體（不含弩、不含背帶） |

### 姿勢與掛點
- **姿勢（請照概念圖）**：人物**側身、背部朝向鏡頭，頭回望鏡頭**（over-the-shoulder 回頭姿態）；一把長劍斜背在身後，劍柄露在肩上方，劍鞘斜跨過背。不是正面、也不是單純的側面。這個姿勢是裝備頁的標準站姿，之後每位角色都照這個構圖。
- **機關與背上的劍共存**：人物背後本來就有斜背的劍，所以弩掛在**左肩**時要和劍鞘、劍帶的前後關係處理好（弩在劍帶外側還是內側、背帶如何與劍帶交錯）。請在示範裡直接畫出來，並在圖層順序圖上標明；若發現掛左肩與背劍在這個姿勢下會互相打架，請提出替代掛點讓我們討論。
- **「左肩」是角色自己的左側**：在這個背對鏡頭的姿勢下，角色的左肩在畫面的哪一邊，請在示意圖上標明（我們不預設）。
- **諸葛連弩掛在角色自己的左肩**（畫面位置隨朝向，圖上大致在人物背後偏左上）。請在示意圖上標出：
  1. **掛點**：弩圖左上角對人物畫布的座標（2× 像素）。
  2. **旋轉角度**與**縮放**（相對於單獨那張弩圖）。
  3. 弩與頭髮、肩膀、披風的**前後遮擋**。
  4. 背帶的起點與終點（肩上扣具到弩身）。
- 先交「**裝備前／裝備後**並排預覽」＋「**圖層順序圖**」，確認方向後再擴充其他部位。

### 其他部位
頭、身體、手、足、武器這一階段**不做紙娃娃**，只放裝備格內的小圖；看示範通過後再決定。

## 六、這一頁的資料規則（請設計時考慮）
- 裝備欄固定 **8 格**：主武器、副武器、頭部、身體、手部、**足部**、飾品、**機關**。
- 副武器可能被鎖定（例如雙手武器），要有停用樣式。
- **沒有「重量」、沒有「整備」**，概念圖上這兩項不用畫。
- 數值只有六項：**攻擊、命中、防禦、速度、暴擊、閃避**；裝備有加氣血或內力上限時才多列。
- 詳情只顯示**目前點選那件裝備自己的加成**；換裝前後的總值變化只在「更換裝備」視窗出現。
- **特殊效果**可能很長，右頁下半是可捲動區。

## 七、交件順序與驗收
1. **先交**：卷軸兩頁與左面板（A、E、F）＋裝備格（C）＋俠客卡片（B）——整頁骨架最急。
2. **再交**：右頁元件（G）、更換裝備視窗（H）、物品圖示（I）。
3. **最後**：紙娃娃（第五節）示範。

**驗收看實機截圖**：位置有沒有擋到文字與按鈕、風格是否與道具頁一致、右頁文字（白字黑框）是否好讀、裝備格小圖放不放得進、可拉長的元件拉長後是否變形。
