## 二、有交，但屬於「補繪／延伸／暫用」（風格要靠實機驗收）

對方的說明檔列出：
- **參照補繪（`reference-repaint`）**：書房後層 `bg_study`、卷軸 `scroll_body`、詳情墨暈 `detail_art_bg`／`detail_art_bg_empty`。
- **暫用（`provisional`）**：`confirm_panel`。
- **16 組通用物品圖**：參照概念圖風格新畫，不是原圖摳取。
- **延伸（`style-extension`／`source-derived-extension`）**：選擇隊友視窗 `pick_panel`、隊員卡四個狀態、氣血內力條、類別章與用途章、分隔線、缺少的按鈕狀態。

## 三、對方明講的限制（要記得）
1. `scroll_body.png` 含景物，**不能平鋪**；固定 1944×1012。其他頁要用，需把景物拆成獨立圖層。
2. 前層裝飾沒有還原概念圖中的大型劍／茶壺。
3. 詳情區右緣原本超出安全區 2 像素：內容要裁在 x ≤ 1128。
4. 預覽圖不是遊戲截圖，裡面的物品與章只是示範位置。
