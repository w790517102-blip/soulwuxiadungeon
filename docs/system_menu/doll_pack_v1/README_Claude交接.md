## 建議接線：全畫布疊圖

`layers/` 的九張圖全部為508×972 RGBA，共同原點(0,0)。放在同一個角色容器，位置、旋轉、縮放均相同；圖內已完成武器與機關對位，不要再對單層套局部素材的掛點變換。

順序由後到前：

1. `doll_back`：後方披風與衣襬。
2. `doll_weapon_back`：長劍上段／背後部分。
3. `doll_mech_back`：連弩後托藏入肩背的部分。
4. `doll_body`：第四階身體衣料。
5. `doll_cloak_front`：第四階披風前片。
6. `doll_weapon_front`：在背部衣料前方可見的劍柄、劍鞘。
7. `doll_mech`：連弩本體可見部分。
8. `doll_strap`：連弩皮革背帶、扣具與固定環。
9. `doll_front`：母圖頭髮／臉，以及本品階需在前方遮擋的肩領、近側手臂部分。

這是保留原七層相對次序後增加武器前後層的**接口提案**，尚未與Claude實機確認。若現有節點命名不同，可以映射這九張圖，不必重構整個裝備頁。

- 卸下武器：兩張 `doll_weapon_*` 一起隱藏。
- 卸下機關：`doll_mech_back`、`doll_mech`、`doll_strap` 一起隱藏。
- 衣裝常駐：`doll_back`、`doll_body`、`doll_cloak_front`、`doll_front` 必須整組切品階，不能只換 body，留下舊品階衣領或衣襬。
- 沒有正式外觀的其他機關：不顯示這三張機關層；仍可正常裝備使用。

本輪是可見表面的分層試裝，不是任意拆掉披風後仍能露出完整裸身的全身解剖模型。未繪製被衣物完整遮住的身體；保持同一品階衣裝整組使用。

## 局部素材與掛點

`assets/longsword_sheathed_local.png` 是直立完整長劍／劍鞘，劍收在鞘內。`assets/zhuge_crossbow_local_360x220.png` 是360×220局部連弩，仍有透明留白。全畫布版本已處理前後遮擋，優先用全畫布版本接入。

局部連弩的本次試裝：先水平翻轉「裝備本身」，再縮至280×171，放在角色畫布(2,277)，旋轉0°、局部原點(0,0)。角色沒有鏡像。素材變換框左上角與人體左肩(132,302)是不同概念，不能混用。

長劍局部先等比調整高度850，再以Pillow正20°逆時針旋轉（畫面中呈劍柄左上、鞘尖右下），旋轉包圍盒左上放在(56,101)。若改用Godot角度慣例，請依實際圖形核對方向；全畫布版本不需做這個轉換。

`mounts_and_layers.json` 記錄局部變換、全畫布尺寸、掛點與前後關係。背帶主要帶身讓到木製弩身後方，保留固定環在前；機關後托一部分藏於肩背，頭髮／衣領再作最前遮擋。所有坐標皆為2×像素，不是1152×648的邏輯值。

背帶與扣具位置是這次組圖上的對位標註，供試裝檢查；若美術驗收要求移動機關，相關遮擋與背帶必須一起重調，不能只拖弩身。
