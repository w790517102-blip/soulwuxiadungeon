# 武術頁 V2｜以已驗收概念圖摳圖、局部清底

## 本輪正式變更

1. 左板主圖示表示「內功心法本身」，不是快遲柔剛的屬性。
2. 屬性採概念圖原本的**菱形圖章**，快／遲／柔／剛各一個檔案。選單只顯示當前屬性的**一枚**；取消四枚並排、閃亮選中其中一枚的做法。
3. 快圖章不含藍色閃亮外框；其藍光沾到遲圖章左角的部分也已清除。
4. 內功標題條取自原概念圖，左側小圓箭頭移除。
5. 左右面板及下方搭配區使用原圖框邊，不再使用V1另畫的標準框。
6. 竹林山水底圖整理成可疊人物的背景；角色、數值、說明文字仍由程式放入。

## 來源與處理範圍

使用沒有彩色圈線的《水墨武俠武術介面.png》為來源，與老闆本輪圈選圖是同一張概念圖。

- **直接摳圖：**內功打坐圖示、內功標題條、菱形圖章，以及框邊原件。
- **原框＋清底：**左右抽屜、搭配底板。內文、圖示等動態內容清掉後，將原圖框邊覆回；native資料夾內的original_frame圖層，是未縮放的來源像素，並已做逐像素核對。
- **需要復原：**人物、文字、整片面板遮住的山水，在平面概念圖裡沒有可直接取回的背景。這些部分使用圖像編修補底；另保留可見的原竹葉、山崖等局部來源像素。**整張背景不宣稱是百分之百原始像素。**
- **快圖章：**原快字和中心面保留；被藍光遮住的普通邊緣，以原圖剛圖章的未發光邊緣配回。遲圖章角落的鄰近藍光污染，以其自身另一側邊緣補回。這是原件清理，不是重畫一組不同風格圖章。

四張新生成的單字書法版已從本輪正式交付項目撤下，本包正式屬性素材全部是菱形圖章。

## 接入注意

這是針對本輪圈選範圍的V2修改包，**不是整套43張素材的重製合集**。未列入本輪修改的分類圖示、名帖、列表列等，仍需依老闆後續驗收選用。

工程輸出維持2倍圖、1152×648邏輯畫布。左右框與搭配框採**保持原比例縮放、透明留邊**裝入原規格尺寸，以免把原圖框硬壓變形。因此不能只替換V1貼圖卻完全沿用原內容座標。

`manifest.json`內有每張圖的native_size、native_scale及fit_padding_px；原件座標可用以下方式換算：

`圖內2倍像素座標 = 原件座標 × native_scale + fit_padding_px`

再除以2即為圖內邏輯座標。左框內功主圖及單一屬性中心已另列於inner_panel_anchors_px。按鈕和文字需依這次概念圖比例重新對位。

原圖搭配板比例與上一份386×174邏輯框差異較大；本包保持原比例縮入，左右有透明留邊。若要更接近概念圖的搭配板寬高，請由Claude調整該區布局，直接採用native/combination_clean.png。**不要把它當V1相同掛點的盲換圖。**

圖章用單一TextureRect即可：依當前內功屬性切換四張圖之一。一般／選中兩態不是這一輪的需求，不要重新排四枚或加回藍色選中光。

來源標題條有兩個選項：固定標題可用含文字版；若程式自行繪字，請用空白版，避免文字重疊。

原框層本身內部透明；clean版已含清空紙面，兩者是不同組法，無須重複疊框。主背景是完整紙面矩形，可為不透明；框體外圍、圖章外圍、圖示外圍有真Alpha。
