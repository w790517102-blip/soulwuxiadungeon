## 接入

將六張根目錄PNG放入 assets/UI/martial/ 即可，檔名按CSV。不要將preview或masters加入自動圖示搜尋。masters保留生成原尺寸，方便後續改版；根目錄才是正式尺寸。預覽上的名稱只供對照，不烙入PNG。內功可直接縮給搭配區。
