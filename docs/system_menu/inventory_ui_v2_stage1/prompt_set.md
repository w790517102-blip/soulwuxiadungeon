# 生成提示規格摘要
模式：內建圖像生成。所有素材要求真透明背景，無文字、無外加稀有度光環。
- 一般分類：七種中國武俠簡單類別符號，米灰、飛白、紙紋、刻痕、輪廓有別。
- 選中分類：另外繪製同七類金色符號，少量柔光，並非一般版調色。
- 分類底板：深皮革、舊金細框、四角完整、無內文與分隔。
- 藥草：可辨識的紮束草藥和根鬚，淡綠沉色、灰黑墨線、乾筆纖維。
- 鐵劍：普通完整直劍、樸素護手、暗色握柄與少量沉紅繩，墨線和飛白。
- 書：斜置線裝書、灰藍封面、空白米紙題籤、磨損紙頁、暈染與纖維。
- 三劍：濃墨厚重闊劍；細長微彎軟劍與一抹淡紫；留白古樸短劍與細刻紋。古劍另作去除外圍霧光的編修。
- 狀態光暈：橫向淡金乾筆、左右透明漸隱、細金線、左小菱形；後製尺寸和 Alpha 上限遵規格。
