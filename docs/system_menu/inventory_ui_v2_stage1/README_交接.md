# 《語破江湖》道具頁 V2｜第一批 A/B/C

本包為第一批美術驗收素材，與 V1 分開保存。共 32 張新 PNG：分類圖示 14、分類欄 1、狀態疊層 5、三件道具大小圖 6、三把劍對照大小圖 6。

## A 分類欄
`assets/UI/inventory/` 中含七類米灰一般版與金色選中版，各 72×72。兩版來自各自繪製的原畫，沒有把物品縮圖改白，也沒有用一般版程式換色產生選中版。
`cat_panel.png` 為 262×880 新繪完整邊框；上下收尾均保留。

## B 半透明狀態疊層
`row_selected.png` 786×96，Alpha 最大 140/255（54.9%）；`row_hover.png` 與 `row_disabled.png` 最大 64/255（25.1%）。左右最外欄 Alpha 均為 0。選中列有左菱形與上下細金線，移入列無菱形。
分類選中 262×116、導航選中 220×96 同樣為透明金色光暈疊層，最大 Alpha 140。

**接法：一般底 → 狀態疊層 → 圖示／文字。** 不可把 selected 視為替代一般底的完整皮膚，否則底板會消失。`row_normal.png` 保持 V1 不變；本包 `references/` 另附三張 V1 normal 供測試，並非替換檔。
採一般 source-over Alpha 疊圖；亮金是視覺效果，不要求引擎使用 additive 混色。

## C 水墨程度示範
正式檔名先提供 01 藥草、05 鐵劍、12 線裝書：小圖 80×80、大圖 380×560，同件道具對應相同原畫；小圖以辨識輪廓為優先。
`samples/` 另提供 heavy 濃墨闊劍、flexible 淡墨軟劍、ancient 古樸刻紋短劍，各有大／小圖。它們是氣質對照，沒有指派稀有度，也沒有替換其他正式編號。
這批保留物件原貌，以墨線、飛白、紙纖維質感、沉色暈染呈現；請用本批預覽與實機確認是否要再提高水墨程度。

## 製作方式及驗證
使用內建圖像生成繪製新原畫，並作分切、等比縮放、透明留白、UI 精確尺寸、細線與 Alpha 整理；不是從概念圖原封不動摳出的素材。
類別圖示以簡單符號為主，實際物品則保留物件細節。光暈以生成的乾筆金色素材加工，hover／disabled／緊湊疊層為同套素材的介面狀態變體。
全部新 PNG 已檢查 RGBA、透明區、尺寸；光暈已檢查 Alpha 上限與左右完全透明，並疊在原 V1 紙紋上檢視。這不等於遊戲引擎內驗收；尚未改動程式或測試引擎。
詳細檔案、尺寸、透明度和來源見 `asset_manifest.json`。
