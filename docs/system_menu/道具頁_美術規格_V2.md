## 一、已定案的規則（請所有後續素材照做）

### 1. 物品圖示的風格：保留原貌的水墨（丙方案）
| 項目 | 規則 |
|---|---|
| **共同原則** | 道具長相**保持原樣**（一眼認得出是什麼），輪廓線與質感像水墨：墨線、紙紋、飛白邊、濃淡。**不要**畫成寫意的筆墨抽象圖，**不要**卡通、塑膠感、高飽和 |
| **上色** | **可以保留物品本身的少量顏色**（例如玉佩的綠、劍穗的紅、藥草的綠），用**水墨武俠風格的上色邏輯**：色彩要「洗過」，偏淡、偏沉、有暈染，不鮮豔。顏色面積不要蓋過墨色 |
| **小圖**（清單 80×80） | 輪廓清楚第一，細節次之，背景透明 |
| **大圖**（詳情 380×560） | 同樣的風格，可以有較多筆觸與質感；允許金屬等材質的**少量**光澤，但不要立體漸層 |
| **你們給的青銅劍（裝備頁概念圖）** | 就是這個方向的標準示範 |

### 2. 同類道具靠「氣質」區分，不靠華麗
例如玄鐵劍：粗重闊身、濃墨大面積；紫霞軟劍：細長彎曲、飛白淡墨、一抹淡紫；湛盧：古樸短劍、細線刻紋、留白多。
**稀有度不畫在物品圖裡**（見下方第四節，由介面顯示）。

### 3. 左側分類圖示：**不是**道具圖示
分類圖示是「類別符號」，風格就是你們自己的概念圖左欄（錢袋、草葉、符籙、藥草、箱子、卷軸）：**中國武俠風的單色符號——造型簡單、輪廓一眼能認，內部有紋理、有辨識度**。

### 4. 頁面統一
之後的**所有系統頁面都統一用這套道具頁的風格**（背景、導航、盤纏、按鈕、清單、詳情元件視為整套選單的標準件）。裝備頁的概念圖（三欄卷軸、中央全身像）我們已收到，當作之後的參考，**目前先不開工**。

## 三、背景重畫、補前景（這一版最大的修改）

### 問題
V1 書房背景的**桌面與牆交界（透視地平線）畫得太高**，桌面佔了下半部太多，前景物件（劍、茶壺、燭台）放不上桌面，也放不進不遮擋介面的位置。

### `bg_study.png` 重畫（尺寸不變：2432 × 1424，四邊各含 64 像素出血）
1. **地平線降低**：牆與桌面的交界約在畫面高度 **45%**（約 y = 640／1424）。這條線大多被卷軸擋住，**卷軸左右兩側要看得到**。
2. **桌面透視要一致**：從地平線向畫面前方延伸，木紋透視逐漸變寬。
3. **卷軸像放在桌上**：卷軸（`scroll_body`）底邊落在桌面，背景要留出自然的落影位置，不要讓卷軸看起來飄在牆前。
4. 牆面保留竹林、遠山、窗光、燭光氣氛（維持現在的風格）。

### 前景物件（這次請交）
前景只能出現在下列**三個安全位置**（邏輯座標，皆在桌面上）：
