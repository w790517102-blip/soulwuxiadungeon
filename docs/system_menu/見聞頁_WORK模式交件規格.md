# 見聞頁｜WORK 模式交件規格（精準驗收版）

> 前置：CHAT 模式已出三張概念圖（`lore_refs/concept_63.webp` 神怪、`concept_64.webp` 豪傑、`concept_65.webp` 奇物），方向認可。
> 這份給 WORK 模式做正式美術包。概念圖只當**風格與版型參考**，以下條目**以本文件為準**，與概念圖衝突時聽本文件的。

## 一、與概念圖不同的地方（必讀）
1. **書的位置與層級**：概念圖把攤開的書放在三本書「下方」。實際要的是：點一本書後，**那本書浮到比桌面前景還靠近玩家的位置**（最上層），蓋過桌面、書架、前景擺設，並把其餘畫面壓暗。所以攤開的書**不需要畫進桌面場景裡**，請把它當成**獨立浮起的一件物件**交（背景透明、四周留落影空間）。
2. **三選一的書架畫面**：三本書並排即可，**不要同時出現攤開的內頁**。書架用斜放的書（概念圖那樣，看得到書側邊），另交正面平放封面，花紋位置與顏色必須一致（詳見 `見聞頁_內頁概念圖委託.md` 第五節）。
3. **「上筆／下筆」側邊標籤**：概念圖畫了，但實際操作是點右頁翻下一筆、點左頁翻上一筆，滑鼠到頁面邊緣會出現箭頭。**請不要畫這兩顆側標籤**；若想保留，請當成獨立的小元件另交，不要烤進書本。
4. 「江湖見聞錄」直排牌與「江湖如逆旅，幸有同路人。」小牌：**要保留**，放在書架畫面的左側（浮起書本時被壓暗）。請與書本分開交。
5. 頁面四邊**不可有貼邊裝飾**（概念圖的血色枝條、墨枝、花朵貼著頁緣）：翻頁時頁面沿書脊彎曲，貼邊的花紋會被拉變形、被裁掉。請把裝飾往內縮，或把四邊 24 邏輯 px 內保持乾淨。

## 二、每本書的欄位（左頁「詳細資料」）
概念圖的欄位**超過我們目前有的資料**，已標註。程式只放有資料的；沒資料的欄位請**不要畫死**，改成可隱藏的版型（欄位標籤與欄位底分開交，程式決定顯示哪幾列）。

| 書 | 欄位（概念圖） | 目前有資料 | 暫無資料（先不顯示） |
|---|---|---|---|
| 奇物 | 類型、效果、取得方式、相關記載 | 類型、效果、敘述 | 取得方式、相關記載 |
| 豪傑 | 身分、經歷、性格、擅長、相關人物 | 人物誌（一段文字） | 全部分欄 |
| 神怪 | 種族、等級、氣血、攻擊、防禦、速度、屬性、技能、掉落物、相關記載 | 種族、經驗、氣血、攻擊、防禦、速度、屬性、掉落物、技能 | 等級、相關記載 |

→ 請把**每一列**做成「標籤牌＋文字欄底」兩件獨立元件，列與列間距固定，程式依資料決定放幾列。豪傑目前只有一段人物誌，請另備一個「單一大文字區」版型。

## 三之二、補充：前景擺設與吊飾（本回合一併摳）

**A. 前景擺設（書架畫面用，浮起的書在它們上方）**
| 檔名 | 位置（邏輯 px，1152×648） | 說明 |
|---|---|---|
| `lore_fg_left.png` | 左下，約 x 0–210、y 430–648 | 左前景：墨筆、硯台、墨罐等（概念圖左下那組）；貼畫面左下角 |
| `lore_fg_right.png` | 右下，約 x 960–1152、y 420–648 | 右前景：書卷、攤開的卷軸（概念圖右下那組）；貼畫面右下角 |
| `lore_title_plate.png` | 左側直排牌（見上表） | 「江湖見聞錄」卷軸牌，與下方小牌是同一塊左側卷軸；請分成兩件獨立交 |
- 不可遮到畫面下方中央的「返回」「目錄」「合上」按鈕（約 x 400–760、y 586–628），也不可遮到三本書。
- 每件只交一張透明 PNG，**物件位置照概念圖，不要為了入鏡自行搬動或縮放**；落影與物件分開交。

**B. 書的吊飾（流蘇、銅錢、玉墜）——保留，並另交 3D 用貼圖**
- 先前說的「不要畫」是指「上筆／下筆」側邊標籤與貼邊裝飾，**吊飾不在此列，請保留**。
- 吊飾要能在程式裡輕輕擺動（開書時、浮起時、滑鼠移上去時晃動），所以請把每本書的吊飾**從書本上分離成獨立透明 PNG**（連同繩結與穗），書本本體上對應位置補好底、不要缺一塊。
- 命名：`lore_charm_<cat>.png`；附掛點（繩結接在書上的像素座標）與建議轉軸，寫在交件說明。
- 若已另備 3D 用貼圖（網格或多段貼圖），請一併交，並註明使用方式與尺寸。

## 四、驗收項目（交件時請附自檢）
1. 所有檔名、尺寸、RGBA、透明邊與上表相符；列出每張的實際像素尺寸。
2. 左頁、右頁在書脊那一側（右頁左緣、左頁右緣）已畫出裝訂暗部，且**四邊 24 邏輯 px 內無貼邊裝飾**。
3. 三本書的左右頁分區座標一致（見 `見聞頁_內頁概念圖委託.md` 第二節），程式用同一套座標放字。
4. 斜放圖與正面封面疊合比對花紋位置、色相（附疊合圖）。
5. 所有會變的文字一律留空：名稱、數值、說明、頁碼、進度；固定標題可烤入。
6. 附一張「各頁在 1152×648 畫面中的示意」確認比例，並註明哪些是烤入的固定字。
