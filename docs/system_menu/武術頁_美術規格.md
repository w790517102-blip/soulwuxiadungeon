# 武術頁｜美術需求（給共邊國）

> 做法：**不重畫大卷軸**，沿用裝備頁那張。只重畫「中間頁面板塊」，蓋在卷軸內頁上。左右兩個抽屜、把手、中央搭配區都在這塊板塊的範圍內或疊在它上面。
> 尺寸一律交 2 倍圖（遊戲邏輯畫布 1152×648，圖 2304×1296 對半縮），透明底 PNG/WebP。

## A. 中間頁面板塊（主件）
- 範圍：邏輯 x 178–1102、y 92–578，即 **924×486**，交圖 **1848×972**。
- 內容：卷軸內頁的紙面底（可含墨痕、竹影、遠山等裝飾），**中央要留出人物位置**（人物站在 x 468–720、y 66–578 一帶，可以略微遮擋在板塊之上，不用畫進去）。
- 左右兩側要能讓抽屜蓋上去；抽屜收起時板塊本身要完整好看。
- 下緣（y 404–578、x 420–806）會放「內外功搭配」底板，這一區請避免高對比細節。

## B. 左右抽屜（各一張，展開狀態）
- 內功心法抽屜：邏輯 236×486（交 472×972）。
- 外功武術抽屜：邏輯 266×486（交 532×972）。
- 要有：標題列（內功心法／外功武術）位置與空白標題條、內容區紙面。文字由程式放，**底板不要寫字**。
- 抽屜與中間板塊要有「疊上去」的邊緣陰影或紙邊。

## C. 抽屜把手（左右各一，收起／展開兩態）
- 把手各約 38×64 邏輯（交 76×128），貼在抽屜外緣，收起時仍露在畫面上。
- **箭頭方向**：左抽屜收起時指右（▶，點了往右展開）、展開時指左（◀）；右抽屜收起時指左（◀）、展開時指右（▶）。
- ⚠ 回饋：上一版概念圖**右邊把手箭頭畫反了**，請照上面方向修正。

## D. 左側窄版名帖（同行俠客列）

- 不放氣血內力。頭像位置請留成可替換的框，由程式放頭像與名字。
