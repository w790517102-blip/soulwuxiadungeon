# 見聞頁｜首頁概念圖委託（給共邊國 梨蕎、澂）

> 這次**只要首頁一張概念圖**。豪傑頁、奇物頁、神怪頁的長相，等首頁定案後逐頁再討論，不用一次畫完。
> 這是一款典型的 RPG：**能收納就收納、能摺疊就摺疊**，首頁不要塞資訊，像一本「江湖見聞錄」的目錄。

## 一、首頁要做什麼
玩家點開「見聞」分頁，第一眼看到的是**目錄**：三個分類的入口，點進去才看到該類的清單與詳情。

- 三個分類（名稱已定）：
  1. **奇物**：遇過、拿過的道具與器物的圖鑑。
  2. **豪傑**：認識的人物。
  3. **神怪**：交手過的敵人。
- 每個入口建議帶：分類名稱、一個代表性的水墨小圖、**收錄進度**（例如「已錄 12／40」）。進度數字由程式放，請留位置。
- 沒有任何收錄的分類也要好看（空狀態）：入口仍在，進度是 0，圖示可以是淡的。
- 可有一塊**最近新增**的提示區（例如「新錄：醉語老拳」），先留位置即可，內容由程式填。
- 「江湖如逆旅，幸有同路人。」那塊小牌與紅印**屬於見聞頁**，請放在首頁一個合適的角落。

## 二、必須守住的規格
1. 畫布 **1152×648**，交 **2 倍圖（2304×1296）**。
2. 上方分頁列（狀態、道具、裝備、武術、隊伍、**見聞**、任務、系統）與下方「返回」鈕**沿用現有的，不用畫**，位置請留出（返回鈕約 x 494–659、y 586–624）。
3. 大卷軸沿用現有那張（與道具頁、裝備頁同一張），只設計卷軸內頁（約 x 158–1130、y 69–575）。
4. 桌面前景（書、劍、茶具）可自由設計是否換，但**不可擋到內容與按鈕**。
5. **所有會變的文字一律留空**：分類名稱可烤進入口牌，但進度數字、最近新增、任何條目名稱都不要畫進圖裡，由程式放。
6. 固定標題用繁體；字體實際會是標楷體，請以這個字形的氣質設計標題牌。
7. 風格與現有頁面一致：書房桌面、宣紙、水墨、古金邊飾、黑墨牌。可參考裝備頁、武術頁。
8. 預留之後的延伸：目前是三類，之後可能再加（例如地誌、傳聞），所以入口排法請不要寫死成「剛好三格填滿」，要能自然多一兩個。

## 三、請一併交的
- 首頁概念圖一張（完整畫面）。
- 入口的狀態示意：**一般、滑鼠移入、選中、尚無收錄**（不必各畫一張完整頁，圈出來或小圖即可）。
- 簡短說明：你們預想「點進去之後」的畫面走向（例如清單在左、詳情在右，或抽屜式展開），讓我們先對齊方向，細節之後再議。

## 四、我們已知的資料（供設計時參考，不必全部畫進首頁）
- **奇物**：圖鑑有物品大圖、名稱、敘述、效果。
- **豪傑**：頭像、名字、簡介；未遇過的人物顯示為「？？？」。
- **神怪**：欄位最多——種族、經驗、血量、攻防速、命中閃避暴擊、屬性、掉落物、技能。未交手過的同樣顯示「？？？」。
- 三類都有「已解鎖／未解鎖」兩種狀態。
