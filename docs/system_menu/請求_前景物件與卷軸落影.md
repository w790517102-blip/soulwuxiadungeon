### 規則
1. **每個物件一張獨立的透明 PNG**，圖的外框就是物件的邊界（不要留大片透明邊）。
2. 位置怎麼貼：我們的程式用**圖的邊角**貼齊上表範圍——左下的物件用**左下角**貼 (0, 648)、茶壺用**右下角**貼 (1152, 648)、燭台用**右上角**貼 (1152, 70)。所以請把物件**畫在圖的邊角上**（例如茶壺的底部貼在圖底、右邊貼在圖右）。
3. **透視一致**：物件貼在桌面上，底部有接地的淡影；方向與桌面木紋的透視相符（劍躺在桌上、略斜向畫面中央）。
4. **光源**：右側窗光＋燭光（暖橙色），物件受光面在右、背光面在左。
5. **風格**：和背景同一套（細緻、偏暗的暖調寫實／水墨感），不要比卷軸搶眼。
6. **不可擋到按鈕與文字**：特別是 x 300–1012 的底部按鈕。
7. 物件的**大小請不要超出上表範圍**（左下最高 128 邏輯像素，也就是 256 像素；茶壺約 58 邏輯像素高）。
8. 燭火動畫（選配）：`fg_candle_flame_1…4.png`，48×64，4 幀循環。

## 二、卷軸落影

### 現況
卷軸看起來略微浮在桌上，沒有落影。我們先用程式後製了一版（見 `scroll_shadow_ours.png`，供你們參考位置與強度），**你們的版本請取代它**，做得更自然。

### 規格
| 項目 | 規格 |
|---|---|
| 檔名 | `scroll_shadow.png` |
| 尺寸 | **2136 × 1204**（邏輯 1068 × 602：卷軸 972×506，四周各多 48） |
| 放法 | 左上角放在邏輯 (110, 21)，也就是卷軸左上角 (158, 69) 往左上各退 48 |
| 內容 | **只有陰影**：純黑偏暖（約 `#0A0500`）加透明度，**不含卷軸本身**，背景透明 |
| 形狀 | 沿著卷軸輪廓（含上下兩根卷軸軸）向外柔和暈開；**下緣與左右側比上緣深**，下緣往下位移約 14 邏輯像素，模擬光從上方與右側窗打下來 |
| 強度 | 最深處不透明度約 60–70%，邊緣漸隱到全透明；**桌面部分**（卷軸底邊落在桌面上）要有一條明確的接觸陰影，讓卷軸「坐」在桌上 |
| 注意 | 不要讓陰影蓋到牆面上半部的竹子與木柱太多（只有卷軸兩側與下方明顯） |
