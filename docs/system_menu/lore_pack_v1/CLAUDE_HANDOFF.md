# 《語破江湖》見聞頁美術包 v1

本包以《見聞頁_WORK模式交件規格》為優先依據，另兩份文件與三張概念圖用於理解美術方向。素材採概念圖參照重建、透明分件及技術組版；不是概念圖逐像素無損摳圖。請先由老闆確認這版美術，再接入遊戲。

## 交付內容

- `assets/`：55 張 RGBA PNG，實際尺寸見 `asset_inventory.csv`，所有必交檔名完整保留。
- `previews/`：書架、三類開書／未收錄頁、封面對位及異色底透明檢查。
- `layout.json`：兩倍像素的內頁區域、書底掛載位置、前景座標及欄位清單。
- `anchors.json`：三件吊飾的像素掛點、轉軸、縮放及 UV 分段。
- `cover_mapping.json`、`cover_registration_metrics.json`：封面至斜放書的投影矩陣及比對結果。
- `mesh/`：三個可選的分段 OBJ 薄片與 MTL；用於嘗試 2.5D 吊飾，不是有厚度的完整立體模型。

## 請先對齊這些設定

遊戲邏輯畫布為 1152×648；美術為 2 倍圖。人物名稱、筆數、數值、欄位名稱、簡述、頁碼、進度全部由程式繪製，不能把預覽當整張背景使用。書架圖只放合起的三本書，開書是獨立頂層物件。

封面與斜放書採同一張原始封面投影，沒有獨立重畫兩次花紋。書架本體不含吊飾，對應位置已補完整。三本書的內頁共用同一套暖色宣紙、山水與版型；分類辨識由書封、吊飾與程式標題負責，內頁不另烤入紅／藍主題與分類文字。

## 書底與虛擬書貼圖

`lore_book_open_base.png` 為 **1560×1040**，兩個內頁孔洞透明。左頁原點 `(60,40)`、右頁原點 `(800,40)`，兩張頁面不需另外旋轉或縮放。

封面：700×960；斜放書：800×1040。另附每類 96×960 的書脊、700×960 的素色書背，以及共用 1024×128 紙層側邊貼圖。書背為相同黑褐色內襯材質，是額外共用方案。斜放書的紙層與封皮以同源貼圖組成，並非全角度 3D 書模型。

建議將封面、內襯、紙頁貼圖貼到各自網格；頁面外框不跨越書脊。不要把斜放 PNG 當成可以自由轉動的完整 3D 模型。翻頁曲面、雙面 UV、陰影、文字與圖片跟頁面同步的實機表現尚須 Claude 接入驗證。

三本封面的共用進度安全區建議為 `(140,830,460,60)`，數字、進度條及文字全部由程式放入。原規格建議的 y 380–414 是參考，本版改用可避開三種封面花紋的共同安全區：邏輯 y 415–445。

## 吊飾

每件 `lore_charm_<cat>.png`：**256×1024**，已含繩圈、繩結、銅墜與穗。小圈中心掛點約 `(128,10)`，這也是建議轉軸；紋理左上角為原點。

正面封面掛點 `(650,110)`，縮放 **0.55**、角度 **0°**。斜放書的掛點依投影矩陣換算，精確值在 `anchors.json`。擺動時繩圈固定、下端受重力向下；不要把掛點當成素材左上角。放置左上角公式：`掛點 − 轉軸 × 縮放`。

3D 方案使用完整透明底色貼圖，建議雙面、保留手繪明暗的 unlit 材質及 Alpha depth pre-pass；不提供虛構法線貼圖。可選 OBJ 的局部原點已移至上端轉軸，V 分界為 0、0.35、0.60、1；共有三段薄片、六個三角形。OBJ 尚未綁骨或加動畫，Claude 可依分界做下垂與擺動。反面使用相同圖案會呈鏡像，不代表真實背面造型；若鏡頭需繞到背面，應另補背面材質或厚度模型。

## 前景

左件 420×436，放在兩倍畫布 `(0,860)`；右件 384×456，放在 `(1920,840)`。分別對應邏輯 `(0,430)`、`(960,420)`。兩件皆與陰影分開，活動物件不能再烤進桌面。中央按鈕安全區邏輯 `(400,586,360,42)` 不會被這兩件覆蓋。

前景為參照重建版，盡量保留墨筆、硯台、墨罐、卷軸的組合和方向，並非原圖一比一 Alpha 抽取。主底卷軸也是重建空白底板，桌面、導航列、近日新錄內容未畫入。

## 驗證與界線

已逐檔檢查 PNG 解碼、RGBA、尺寸與透明像素，並附實際尺寸／SHA-256 清單。吊飾以米色與藍色底複驗；封面對位附原圖、斜放逆投影、50% 疊合三欄。誤差來自投影的兩次像素取樣，沒有重新生成花紋。

本包附三類開書與未收錄的 1152×648 組版示意，背景已壓暗，書在前景之上。這些是素材組版檢查，不是 Godot 實機截圖。尚未測試：實際字體排版、資料超長處理、翻頁網格變形、點擊熱區、吊飾物理、GPU 透明排序。請在正式實機驗收時一併確認。
