# 見聞頁｜三本書的內頁概念圖委託（給共邊國 梨蕎、澂）

> 先出**概念圖**，不是最終素材。每本書一張「攤開的跨頁」，確認風格後再拆成正式的左右頁。
> 背景：見聞頁已定案為三本書（奇物、豪傑、神怪），點一本浮到前面翻開，一筆資料兩頁。翻頁的彎曲動畫由程式處理，美術只需畫**平放的靜態頁面**。

## 一、要交什麼
**每本書一張攤開的跨頁概念圖（左頁＋右頁並排，平放正視，不要斜角）**，共 3 張，另各附「未收錄」的樣子（可畫在同一張的角落示意，或另出一張）。
- 每本的左右頁各為 **350×480 邏輯**（跨頁 700×480）；交 2 倍圖 **1400×960**。
- 頁面中央書脊處，右頁的書脊在左側、左頁的書脊在右側，靠書脊那邊請畫得略暗（裝訂凹陷）。

## 三、三本書的差異（風格要一眼能分，但紙張與邊框語彙一致）
- **奇物**：器物珍藏的氣質。條列區偏「圖鑑」。
- **豪傑**：人物誌的氣質。左頁以一段文字為主，可略留肖像或印章位置。
- **神怪**：妖異、危險感，可有紅黑點綴。左頁數據欄位最多（約 6～8 行），請讓條列區整齊。
- 封面的顏色建議延續概念圖：奇物偏棕金、豪傑偏深藍、神怪偏暗紅。

## 四、必須守住
1. **頁面四邊不要有貼邊的裝飾或花紋**（至少左右邊緣要平整）：翻頁時是沿書脊彎曲，貼邊的花紋會被拉變形。
2. 所有會變的文字都**留空**，由程式放：名稱、數值、說明、頁碼。字體是標楷體。
3. 頁面內避免太細太淡的線條，翻頁彎曲時會有鋸齒。
4. 左右頁版型各三種（共 6 個）要能**共用**同一套尺寸與分區，這樣程式才能依資料動態填入。
5. 「未收錄」要有：右頁是灰淡的「？」圖框與「？？？」標題，左頁是「尚未收錄」；風格比已收錄的更淡、更舊，像還沒寫上的空白頁。

## 五、補充：書架斜放圖（另一批，之後再出）
概念圖裡的書是斜放、看得到書側邊的。程式的做法是：每本書請交**兩張**——
1. **書架用的斜放圖**（帶書側邊厚度，就是概念圖那個樣子）。
2. **正面平放的封面**。
點書時斜放圖移到前面並旋轉歪斜回正，再淡入成正面封面，接著封面翻開。**兩張的花紋位置與顏色必須一致**，否則淡入時封面會跳一下。這批可以等內頁概念圖定案後再做。
