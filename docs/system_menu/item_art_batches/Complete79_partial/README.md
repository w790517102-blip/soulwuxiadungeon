# 《語破江湖》道具專屬美術整合包

總清單79件，目前實際交付79件、158張PNG，其中本輪新增71件。progress.csv逐件列出製作與驗收狀態；已製作不代表已獲老闆驗收。

## 接入

將 assets 目錄合併到Godot專案同一路徑，正式檔案位於 assets/UI/inventory/dedicated/。每件都有 <id>_art.png（380×560）與 <id>_icon.png（80×80）。依既有尋圖機制使用；此包未修改任何程式，尚須Claude接入實機驗證。

## 美術與輸出

內建 image_gen 逐件生成獨立原畫，沿用前批已驗收的鐵劍作風格參考：中國武俠水墨、深墨輪廓、克制自然色、乾筆與材質層次；紙紋保留在物件表面，不包含底卡。沒有名稱、數量或稀有度章。書封題籤保持空白；符紙只有抽象筆畫。藥草與藥散以不同葉形、根莖、容器和包裝區分，並非只改顏色。

同件大圖、小圖來自相同原畫。技術輸出僅透明邊界取景、等比縮製、置中及PNG壓縮；必要時對超過上限的PNG減少色表，不改畫布尺寸。每張正式素材小於250000 bytes，四角透明，主體具接近或完全不透明的Alpha。asset_check.json記錄逐檔尺寸、透明、位元組與雜湊；PROMPTS.json保留提示。

overview_79.png呈現全部已製作項目的80像素圖示總覽；previews內分頁呈現大圖及兩種底色的實際80×80小圖。英文ID只在預覽上，不烤入正式素材。預覽是檢視用，不是貼圖。

## 紙娃娃範圍

本包只包含道具大圖與小圖，不製作新增紙娃娃圖層、不改既有角色掛點。刀、槍、筆、琴等可作未來角色的造型參考；實際左／右側、角度、背帶及前後遮擋須配合角色母圖決定，不能直接把庫存圖當成可無縫接入的角色裝備層。

短刀未含刀鞘；瑤琴提供演奏面與側壁，攜行需另製背面、琴袋或支撐背帶，不可把負重直接繫在琴弦上。諸葛連弩是獨立道具構造參考，未依任何角色肩膀對位。
