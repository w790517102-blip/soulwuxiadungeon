**交件問題（待回饋）**
1. **部位文字大小不一**：副武器約 75×27 像素、機關 46×23、飾品 37×21，其他（主武器 53×18、頭部／身體／手部／足部約 35×18）。畫面上「副武器」「機關」明顯比別的大。請統一字級與位置（位置 x 約 127–136、y 約 96–99）。

3. **金光在實機縮小後偏淡**，選中的格子不夠醒目（預覽圖看起來比實機亮）。
4. 灰色剪影大小位置不一（頭部較小、飾品被拉長），可接受但建議統一約 100×95 的範圍。

**V3 套用方式的調整（2026-10-20，老闆定案）**：字大一點且統一、圖示大一點、留白越少越好、一眼看出八格是什麼、格子上不寫裝備名稱（右頁看得到完整資訊）。做法：不用共邊國的「框＋文字」合成底圖，改用純框（`slot_frame_*`），部位名稱與灰剪影各自裁緊（`tools/prepare_slot_parts.gd` → `slots/label_*`、`slots/ghost_*`），程式把八個部位名稱縮放成同樣的字大小（每字 13 邏輯 px）放在格子上緣，其餘整塊是大圖示。上面「交件問題 1（字大小不一）」因此由我們處理掉；原檔保留在 `docs/system_menu/equipment_originals/slots_v3/`。
