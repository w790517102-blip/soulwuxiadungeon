# 武術與內功圖示清單（劉語塵、白書眠；列霄先不做）

> 完整表格見 `武術內功_圖示清單.csv`（Excel 可直接開，含每招的描述，供畫圖參考）。
> 資料來源是遊戲現行資料（SkillDB、InnerForceDB）；已排除敵方專用招式、列霄的招式、測試用招式。

## 規格
- 每個圖示一張透明 PNG，**96×96（邏輯 48×48，2 倍圖）**，圓形水墨風、與 V1 分類圖示同一套（見 `assets/UI/martial/category_*.png`）；圓框外全透明。
- 武術檔名：`skill_<id去掉前綴 skill_>.png`（例如連決劍 → `skill_lianjuejian.png`）。放進 `assets/UI/martial/`，程式找到就用；沒有就退回該武器類別的分類圖示，所以可以分批交。
- 內功檔名：`force_<id>.png`，**256×256**（左面板大圖示用，程式會縮小給搭配區與選單用）。**選配**：目前所有內功共用「打坐人像」，若要每門內功各有象徵圖再交。
- 「未習得」的灰階版由程式處理，不用畫。

### 畫圖提示
- 劍／刀／拳／掌／筆（畫面主體是對應武器或手勢）；恢復類（氣療掌、墨筆舒心、澄心落筆）偏柔和，增益類（鷹眼凝）偏凝神。
- 「臨符」六張是同系列的符紙（燃鋒、固元、疾影、壯力、護脈、啟慧、聚福），請做成一套、用符紋與顏色區分。
- 「持鞘」三張（拔劍持鞘、鞘劍連擊、收鞘於背）是一組：劍與鞘。
