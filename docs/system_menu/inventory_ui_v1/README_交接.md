# 江湖行囊｜道具頁美術拆件 V1

本包為美術拆件／組裝驗收版；尚未修改或部署 Godot 專案。
風格基準：使用者提供的 1536×864 概念 JPEG。
尺寸與檔名基準：道具頁_美術規格.md、道具頁_美術尺寸配置圖.svg。
補傳的江湖行跡錄 SVG 為存讀檔頁，不取代道具頁配置。

## 交付

- `assets/UI/inventory/`：101 張 PNG，檔名及 2× 尺寸對應規格。
- `inventory_assembled_blank_preview.jpg`：實際元件離線組裝預覽，2304×1296。非遊戲截圖。
- `contact_sheet_01…05.jpg`：全元件檢視，標籤只存在檢視圖，不在遊戲素材內。
- `asset_manifest.json`：來源類型、像素尺寸、Alpha 範圍及 NinePatch 邊距。
- `layout_2x.json`：位置與安全區修正。Godot 邏輯顯示尺寸＝素材尺寸÷2。
- `item_groups.json`：01–16 對應通用道具群組。
- `validation.json`：獨立規格尺寸檢查、可解碼及透明度結果。

## 原圖擷取與補繪的區別

這份不是「100%逐像素原圖摳取」。概念 JPEG 有文字、物品及互相遮擋，無法直接還原被擋住的背景。

- 頁籤、貨幣框、分類欄、選中列、按鈕：源圖裁切，移除文字／內容後做尺寸適配與狀態延伸；RGB 並非原封不動。
- 書房後層、無字卷軸、詳情墨暈：內建圖像編修參照概念圖補繪，再裁切／適配指定尺寸。
- 16 組通用物品：參照概念圖風格新繪，並非原圖既有物品的逐像素摳圖。每組固定 80×80 小圖、380×560 大圖，保留物件比例，空白處透明。
- 類別與用途章、分隔線、血魔條、缺少的狀態：以源圖形狀與色系延伸；來源有記錄。
- 本版無字素材需由遊戲動態加上文字；不包含字體、排版程式及互動邏輯。

## 三項必須注意的限制

1. `confirm_panel.png` 是同風格暫用版。規格提到的「既有存讀檔確認面板原件」未隨本次附件提供，所以本版不能宣稱已沿用該原件。拿到原件後優先替換。採道具頁要求的1200×688，而非補傳存讀檔SVG中的880×472。
2. `scroll_body.png` 含景物與邊緣竹葉，不可當作無縫平鋪背景；本版採固定1944×1012。適用其他比例時應把景物拆到獨立覆蓋層，再伸縮紙張。各框／按鈕以NinePatch的stretch模式使用，不使用整張repeat。可拉伸元件的中心沒有文字或中央徽章。
3. 前景裝飾只保留可放進外緣44px高帶狀區的縮小裁切版本，屬選配；未放進組裝預覽，以免侵入24邏輯像素安全區。它們不等同原概念圖中大型劍／茶壺的完整還原。若要大裝飾，需擴大可用外緣或挪動內容，不能直接覆蓋UI。

## 座標衝突與處理

- 安全區：邏輯x24–1128、y24–624。
- 分類欄原x17 → 預覽x24；其原尺寸131×440維持。
- 按鈕原y592、高38，底到630 → 預覽y586，底到624。
- 詳情區原右界1130超安全區2px；所有可交互文字／內容應裁在x1128內。
- 清單表頭28＋8列×48＝412，區塊424剩12為留白。
- 詳情文字欄有最少5行敘述與引用句需求；固定欄高下，長內容應用ScrollContainer，引用句可移到流式內容末端，避免與敘述相壓。不要縮字或省略號代替閱讀。
- 八個頁籤各110，合880，小於底板889，多出9為底板端部留白。
- 預覽裡的物品與類別章僅示範資產位置，不代表遊戲資料對照；實裝按`item_groups.json`建立16組通用圖映射。

## Godot 接入

1. 將assets/UI/inventory/複製到專案同一路徑。
2. 使用1152×648邏輯畫面；PNG以2×匯入，TextureRect最小／顯示尺寸用一半。
3. 背景2432×1424含四邊64px出血，中央裁出2304×1296。
4. NinePatchRect的patch_margin依manifest像素值設定；內容padding另由Control/MarginContainer決定。
5. HP/MP frame疊在fill上，fill透過裁切顯示長度；勿水平縮放整個邊框。
6. 導航8項、分類7項、所有文案、數量、類別、用途與按鈕文字均由程式輸出。分類不保留概念圖的「符器／貴重」。
7. 狀態版檔案分開，不要在互動時替換整張選單。
8. 請先用真實遊戲畫面比對概念圖，通過後才延伸其他頁面。本包通過的是資產規格檢查，不等於美術風格已取得使用者驗收。

## 可重現與來源
