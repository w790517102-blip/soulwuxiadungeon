# 《江湖行跡錄》UI 素材｜生圖規格表（可直接貼給 ChatGPT）

## 0. 貼給 ChatGPT 的開場說明（先貼這段）

我在做一款 2.5D 復古像素風武俠 RPG《語破江湖》，需要為「存檔／讀檔介面」生成 UI 素材。整體風格是：**黑褐底、暗金邊、金色雲紋（中式回紋、卷雲）邊飾，帶一點水墨與舊羊皮紙的質感，朱紅色當重點色**。參考我附上的主選單金色按鈕（黑褐底板＋金色雲紋兩端）。

請遵守：
1. 每個素材**單獨一張圖**，背景請輸出**純白或透明**（我會自己去背），不要畫背景場景。
2. **不要在圖上寫任何文字**（文字由遊戲程式疊上）。
3. 畫面為俯視正面的平面 UI 元件，不要透視、不要陰影投到背景外。
4. 邊框與邊角要左右上下**對稱**，因為我會切成「九宮格」讓中央可拉伸：四個角落的裝飾要集中在角落，中央與邊線要簡單、可重複。
5. 尺寸以我給的像素為準（是 2 倍解析度）。若無法精準，請**等比例**輸出，我會再縮放。
6. 同一組的狀態圖（正常／Hover／選中…）要**同尺寸、同構圖**，只改顏色與亮度。

色票：黑褐底 `#130F0C`、較亮褐 `#211A13`、暗金邊 `#6B5629`、亮金 `#D9AD47`、金字 `#DBB860`、朱紅 `#8F1D1D`／`#380F0D`、暗紅警示 `#A63326`、米白文字 `#E8DCC0`。

## 1. 素材清單與各自的生圖提示

> 每項包含：**名稱｜尺寸（px）｜用途｜提示詞**。尺寸是 2 倍解析度；畫面參考大小為 1152×648。

### 1-1 主外框 `chronicle_frame`
- **尺寸**：2176 × 1200（橫式）
- **用途**：整個「江湖行跡錄」視窗的外框與底。
- **提示詞**：
  一個橫式的中式武俠 UI 大外框，2176×1200，深黑褐色底（#130F0C）帶細微舊羊皮紙與水墨暈染質感，外緣有約 6px 的暗金色邊（#6B5629），最外側再有一圈亮金細線（#D9AD47）。**四個角落**有精緻的金色卷雲／回紋裝飾（只佔角落約 90×90px），四邊中段保持簡單的細金線，**中央區域保持素淨深色**，方便放內容。左右上下對稱。無文字、無人物、背景純白（框外）。

### 1-2 標題分隔線 `chronicle_title_rule`（選配）
- **尺寸**：2080 × 16
- **用途**：標題下方的橫向分隔線，可橫向拉伸。
- **提示詞**：
  一條細長水平的暗金色分隔線，2080×16，中央有小小的金色雲紋或菱形裝飾，兩側線條簡單延伸並漸隱，透明背景，無文字。

### 1-3 存檔欄位底（5 張，同尺寸）
- **尺寸**：每張 624 × 176（橫式長方）
- **用途**：左側存檔目錄的單筆欄位底板。
- **共通提示詞**：
  一個橫式的 UI 按鈕底板，624×176，圓角很小（約 6px），黑褐底、細暗金邊，邊角只有極小的金色卷雲點綴，中央大面積留白（因為會放縮圖與文字），左右對稱，無文字，背景透明或純白。
- **5 個狀態，請分別生成（同構圖，只改顏色）**：
  1. `slot_bg_normal`（正常）：黑褐底 `#130F0C`，暗金細邊 `#6B5629`，2px 感。
  2. `slot_bg_hover`（滑鼠移入）：底色略亮 `#211A13`，邊緣轉亮金 `#D9AD47`，微微發光。
  3. `slot_bg_selected`（選中）：**朱紅底 `#380F0D`**，**亮金粗邊 `#D9AD47` 約 3px**，四角金色雲紋更明顯，有一點內發光，最醒目。
  4. `slot_bg_empty`（空白紀錄）：比正常更淡、更暗，邊線可用**虛線**或較淡的金色，帶「尚未書寫」的留白感。
  5. `slot_bg_corrupt`（存檔異常）：黑褐底，邊框為**暗紅 `#A63326`**，帶一點裂紋或破損感，但不要太血腥或刺眼。

### 1-4 縮圖框 `thumb_frame`（2 個尺寸，同風格）
- **尺寸**：小 232 × 134；大 768 × 432
- **用途**：存檔欄位內的小縮圖框、右側大預覽的外框。
- **提示詞**：
  一個 16:9 的「畫框」外框，只有邊框，**中央為純白（我會去背鏤空）**，邊框為細暗金色（#6B5629）加內側亮金細線（#D9AD47），四角有極小的金色雲紋點綴，大尺寸版本的邊框稍寬，無文字。

### 1-5 按鈕（2 款 × 4 狀態 = 8 張，同尺寸）
- **尺寸**：每張 368 × 72（橫式）
- **用途**：返回、上一頁、下一頁、取消（黑金款）；儲存進度、讀取進度、確認（朱紅款）。
- **共通提示詞**：
  一個橫式的 UI 按鈕底板，368×72，小圓角，兩端有精緻的金色雲紋邊飾（參考我附上的主選單金牌，但更小、更簡潔），中央留白放文字，上下邊有細金線，無文字。
- **黑金款**（`btn_normal`／`btn_hover`／`btn_pressed`／`btn_disabled`）：
  - normal：黑褐底、暗金邊。
  - hover：底色略亮、邊轉亮金、微發光。
  - pressed：比 normal 略暗、邊框更粗、有內凹感。
  - disabled：整體灰暗、飽和度降低、邊框暗淡。
- **朱紅款**（`btn_primary_normal`／`hover`／`pressed`／`disabled`）：
  同構圖，**底色改為朱紅 `#8F1D1D`**，邊框金色；hover 更亮更紅，pressed 更深，disabled 灰紅暗淡。

### 1-6 確認視窗面板 `confirm_panel`
- **尺寸**：880 × 472（橫式）
- **用途**：「是否覆蓋存檔？」等小視窗的面板。
- **提示詞**：
  一個中等大小的橫式面板，880×472，比主外框**更深一階**的黑褐底（#17120E 左右），金色邊框，四角有金色卷雲裝飾，四邊簡單、中央完全素淨，風格與主外框一致但更精簡，左右上下對稱，無文字，背景純白。

### 1-7 無縮圖預設圖 `thumb_placeholder`
- **尺寸**：752 × 416（16:9）
- **用途**：存檔沒有縮圖、或是空白紀錄時，右側預覽顯示的畫面。
- **提示詞**：
  一幅 16:9 的水墨留白畫面，752×416，淡淡的遠山、薄霧與一葉小舟的剪影（極簡），整體偏暗、對比低（因為要在黑褐 UI 中顯示），**畫面正中央留一塊乾淨的區域**（我會疊文字），圖上不要有任何文字，不要人物臉部。
