# 江湖行跡錄｜美術交付規格（去背素材直接套用版）

> **以這份為準**。它取代之前的《美術規格書》《美術素材清單》《ChatGPT 生圖規格表》中與本文不同的地方。
> 版面以**目前遊戲裡實際的介面為準**（2 欄 × 5 列、每頁 10 格、上一頁／下一頁；右側預覽與資訊）。概念圖只當**風格**參考，版面不照概念圖。
> 做法同戰鬥素材：**美術把去背 PNG 依下面的檔名放進 `assets/UI/chronicle/`，程式會自動套用**，沒有檔案的元件暫時維持程式畫的色塊。不需要再改程式。

---

## 0. 基本規則（全部素材共通）

| 項目 | 規定 |
|---|---|
| 格式 | **PNG，透明背景（RGBA）**，sRGB |
| 解析度 | **2 倍**：遊戲邏輯畫面 1152×648，素材像素 = 邏輯尺寸 × 2（整個畫面等於 2304×1296） |
| 文字 | **圖上不要有任何文字**（唯一例外：標題橫幅 `chronicle_title.png` 可以含「江湖行跡錄」書法字）。其餘文字都由遊戲疊上 |
| 檔名 | 全小寫、底線，**一個字都不要改**；放在 `assets/UI/chronicle/` |
| 九宮格 | 標示「九宮格」的素材，**四個角落的裝飾要集中在角落，四邊中段與中央要簡單、可拉伸**。遊戲會把中央拉到需要的大小，角落不會被拉伸 |
| 同組狀態 | 同一組的狀態圖（例如欄位 5 種底）**尺寸必須完全相同**，構圖相同，只改顏色與亮度 |
| 風格 | 沿用美術既定的卷軸／羊皮紙／水墨黑金（概念圖那一套）。**重點色：選中＝金色發光邊、異常＝暗紅** |

## 1. 要交付的素材（共 19 張 + 1 個設定檔）

位置欄的座標是**邏輯畫面座標（1152×648）**，括號內是 **2× 像素**，供美術對位使用。

### 1-1 外框與標題

### 1-6 文字顏色設定檔 `skin.json`（選配，文字檔）

文字顏色預設是「淺色字配深色底」。若美術做成**淺色羊皮紙底**，請交一個 `skin.json` 把字改成深色（美術自行決定色票）：

```json
{
  "colors": {
    "title":  "#2A1A0A",
    "gold":   "#5A2A10",
    "text":   "#2A1A0A",
    "dim":    "#6A5A40",
    "corrupt":"#A63326",
    "button_text":          "#DBB860",
    "button_text_hover":    "#FFEBB3",
    "button_text_disabled": "#665C4D",
    "toast":  "#FFF0C0"
  },
  "margins": {
    "chronicle_frame": 48,
    "slot_bg_normal": 12
  }
}
```

各 key 的意思：`gold`＝存檔編號與右側大編號；`text`＝地點、時間、所在場景等一般字；`dim`＝日期、空白紀錄、模式小字；`corrupt`＝「存檔異常」字；`button_text*`＝按鈕上的字；`toast`＝「儲存成功」提示字（有黑描邊）。`margins` 只有在九宮格邊寬需要和預設不同時才寫。

## 2. 這一版**不需要**畫的東西
概念圖裡的下列項目都**不做**：數字印章底（一、二、三）、遊戲時長與氣血內力列與血條、各種資訊圖示、「存檔資訊」毛筆標籤、刪除與覆寫按鈕、捲動條、「確定」按鈕。版面也不改成單欄 5 筆。

## 3. 交付流程
1. 美術依本文檔名與尺寸輸出 PNG，放進 `assets/UI/chronicle/`（沒有也沒關係，沒有的元件維持暫用色塊）。
2. 另外請附一張 **2304 × 1296 的對位預覽圖**（把所有素材疊在正確位置），我用來對照。
3. 工程這邊（我）會：打開 Godot 匯入、截圖比對、必要時微調九宮格邊寬與文字顏色（改 `skin.json`，不改程式）、補上實機驗證。
4. 尺寸或位置要調整時，以本文為準修改本文，我再依新數字調整版面。

## 4. 檢查清單（美術交件前自查）
- [ ] 全部是透明背景 PNG（`thumb_placeholder` 例外，不透明）。
- [ ] 圖上沒有文字（標題橫幅除外）。
- [ ] 同一組狀態圖尺寸一致（欄位 5 張 624×176；按鈕 8 張 368×72）。
- [ ] 外框剛好 2176×1200，且在標題、列表、預覽、按鈕的位置都沒有被裝飾擋住。
- [ ] 兩張畫框（小、大）中央是真的透明鏤空。
- [ ] 欄位底在選中時，金色編號、米白（或深色）地點、日期三行文字仍清楚可讀。
- [ ] 檔名全部小寫、與本文完全一致。

## 5. 皮膚資料夾（多套 UI 皮膚）
素材不再直接放在 `assets/UI/chronicle/`，改成**每套皮膚一個資料夾**，檔名與本文完全相同：

| 資料夾 | 說明 |
|---|---|
| `assets/UI/chronicle/dark_b/` | 黑底欄位版（備用；欄位底是黑底金邊，空白紀錄是淺色羊皮紙） |
| `assets/UI/chronicle/scroll_a/` | 羊皮紙欄位版（**目前預設**） |

- 每個資料夾各自有 `skin.json`（文字顏色、九宮格邊寬）。欄位上的字另有 `slot_gold`／`slot_text`／`slot_dim`／`slot_corrupt`，空白紀錄欄位另有 `slot_empty_gold`／`slot_empty_text`／`slot_empty_dim`，因為欄位底的明暗和右側資訊區的底不同，文字顏色要分開設。
- 切換：程式呼叫 `ChronicleSkin.set_skin("dark_b")`；`ChronicleSkin.available_skins()` 會列出所有有資料夾的皮膚。之後做成讓玩家自己選時，只需要把選擇存起來並在開啟畫面前呼叫它。
- 新增第三套皮膚：建立新資料夾、放入同名素材即可。
