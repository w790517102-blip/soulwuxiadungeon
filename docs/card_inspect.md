# Card Inspect（卡片檢閱模式）V1

戰場是速讀，檢閱是細讀。戰場卡面維持單字狀態（`StageBattleUI.BATTLEFIELD_STATUS_ICONS = false`；設為 true 可讓戰場卡面改顯示 ICON，缺圖退回單字）。

## 操作
- 玩家選擇行動期間（沒有指令選單／選目標／動畫），**左鍵或右鍵點任何卡**（我方、敵方、僚卡）開啟檢閱。
- **目前可行動的我方角色卡：左鍵仍是行動（指令選單），右鍵才是檢閱。**
- 關閉：ESC、右鍵、面板右上「關閉」、點面板外的暗處（左鍵）。
- 檢閱中舞台被鎖住（`stage.busy`），不觸發滑鼠懸停；敵方行動／演出中不可開啟（V1 限制）。

## 演出（`CardInspect.gd`）
被檢閱的卡從牌陣位置前移到鏡頭前、畫面左側、轉正面向玩家；整個舞台蓋一張暗幕（3D 平面，位於該卡之後、其他卡之前），右側面板滑入；關閉時卡片回到原位。**不改 `home_position`，牌陣完全不動。**

## 資料（`CardInspectData.gd`，一個共通容器 `title / subtitle / blocks / statuses / notes`）
- 我方：Lv、內功、HP／MP、行動順位、五維與攻防速命閃會心（目前值）、武器、武學（名稱／內力／簡述，取自 `character_skill_db`）。遊戲資料沒有的欄位（例如防具）不顯示。
- 敵方：種族、屬性、HP、數值、戰鬥情報（依屬性剋制規則算出的弱點／剋制，魘鱗護體說明）。
- 僚卡：所屬、來源、陣營、剩餘次數／回合、位置規則（不吃角色速度）、可否被攻擊／治療、本輪是否已行動、效果說明。
- **目前狀態**：每項 ICON（沒圖退回單字）＋名稱＋效果值＋剩餘回合＋來源。來源只顯示「已記錄」的：技能（`BattleController._apply_single_skill_effect`）、道具（`ItemEffectDispatcher._tag_source`）、Boss 自身護體；沒記錄的不顯示、不猜。另列出目前作用在該角色身上的僚卡效果（同家族只取最高，未生效者標明）。

## 面板（`CardInspectPanel.gd`）
右半邊深色面板，標題、副標、「基本」、「目前狀態」、其餘區塊、備註；內容過長可捲動。獨立的 `CanvasLayer`，不受舞台 HUD 開關影響。
